iOS Universal App Links

✅ Universal App Links configuration is active

This page hosts the iOS Universal App Links configuration for LSL Champions apps. Universal App Links allow your iOS app to handle specific URLs and provide a seamless experience between your website and mobile app.

Configuration Details

Apple App Site Association file: /docs/.well-known/apple-app-site-association

Bundle ID: com.whitneyland.mcpplay

Supported paths: /play/*

Example Universal Links:

https://whitneyland.github.io/play/game/12345
https://whitneyland.github.io/play/scoreboard/football
https://whitneyland.github.io/play/session/abc123

For Developers

To implement Universal App Links in your iOS app:

  1. Add the Associated Domains capability to your app
  2. Update your app's entitlements with: applinks:whitneyland.github.io
  3. Replace TEAMID in the association file with your actual Team ID (Bundle ID is already set to com.whitneyland.mcpplay)
  4. Implement URL handling in your AppDelegate or SceneDelegate

Verification

Test your Universal App Links configuration with Apple's validator:

curl -v https://whitneyland.github.io/docs/.well-known/apple-app-site-association

Note: The association file is served with Content-Type: application/json via the _headers file for GitHub Pages compatibility.
